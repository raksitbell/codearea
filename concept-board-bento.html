Kadane Algorithm

หา subarray ต่อเนื่องที่มีผลรวมมากที่สุดจากรายการตัวเลข

Input: [-2,1,-3,4,-1,2,1,-5,4]

Expected: 6

solution.pyPython
best = float("-inf")
current = 0
for n in nums:
    current = max(n, current + n)
    best = max(best, current)
return best
